Evidence path

  1. ParseRead the as-coded MDS values and assessment date.
  2. Parse structured dataRead MDS XML/JSON plus optional diagnosis, MAR, diet-order, and therapy signals.
  3. Recover document textRasterize PDFs and run local Tesseract OCR page by page.
  4. Qualify evidenceApply deterministic context, conflict, citation, confidence, and look-back rules.
  5. RegroupRun as-coded and as-supported states through the CMS grouper.
  6. ReviewReturn suggested item changes with source evidence for human confirmation.
Supported coding scope

Structured evidence: two NTA diagnoses, six Section I primary classes, K0520C3, and selected GG tasks. Text evidence is always an uncounted review candidate. This is not a general autonomous medical coder.
